================================================================================
OPERATING SYSTEMS: COMPLETE ARCHITECTURE, COMPONENTS, STRUCTURES & COMMANDS
================================================================================

1. CORE KERNEL & SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
- Kernel Types:
  * Monolithic Kernel (e.g., Linux, Unix): Runs core OS services (scheduling,
    memory, drivers, file systems) in kernel space.
  * Microkernel (e.g., MINIX, QNX): Minimal kernel space (IPC, basic scheduling);
    drivers and services run in user space.
  * Hybrid Kernel (e.g., Windows NT, macOS XNU): Combines monolithic performance
    with modular microkernel-style subsystems.
  * Exokernel / Unikernel: Specialized kernels exposing raw hardware or single-
    address-space application images.

- Privilege Rings & Execution Modes:
  * Ring 0 (Kernel Mode / Supervisor Mode): Unrestricted hardware & memory access.
  * Ring 3 (User Mode): Restricted execution for applications; interacts with
    kernel via System Calls (syscalls).
  * Hypervisor Mode (Ring -1): Hardware-assisted virtualization (VT-x / AMD-V).

- Boot & Initialization Sequence:
  * Firmware: UEFI (Unified Extensible Firmware Interface) or Legacy BIOS.
  * Bootloaders: Windows Boot Manager (bootmgfw.efi / BCD), GRUB2, systemd-boot.
  * Initial RAM Disk: initramfs / initrd (Linux), Winload.exe (Windows).
  * Init System (PID 1): systemd, OpenRC, SysVinit (Linux); smss.exe, wininit.exe,
    services.exe (Windows).

2. PROCESS & THREAD MANAGEMENT
--------------------------------------------------------------------------------
- Execution Units:
  * Processes: Isolated address spaces with PID, environment, and resources.
  * Threads: Lightweight execution units sharing a process's memory space.
  * Kernel Threads: Background OS tasks (e.g., kthreadd, System PID 4).
  * Daemons / Services: Non-interactive background processes.
  * Zombies & Orphans: Terminated processes awaiting parent cleanup or adopted
    by PID 1.

- CPU Scheduling:
  * Algorithms: Completely Fair Scheduler (CFS / EEVDF in Linux), Multilevel
    Feedback Queue (MLFQ in Windows), Round-Robin, Priority Scheduling, Real-Time
    (FIFO / RR).
  * Context Switching: Saving and restoring CPU registers, program counter, and
    page tables between tasks.
  * CPU Affinity & Priority: Nice values (-20 to +19), Real-time priorities,
    Processor Groups.

- Inter-Process Communication (IPC):
  * Pipes (Anonymous & Named Pipes / FIFOs)
  * Shared Memory (shm, mmap)
  * Message Queues
  * Sockets (Unix Domain Sockets, Network Sockets)
  * Signals & Events (SIGTERM, SIGKILL, SIGHUP, Windows Event Objects)
  * Remote Procedure Calls (RPC, D-Bus, COM/DCOM)

- Synchronization Primitives:
  * Mutexes (Mutual Exclusion Locks)
  * Semaphores (Counting & Binary)
  * Spinlocks & Read-Write Locks
  * Condition Variables & Barriers

3. MEMORY MANAGEMENT
--------------------------------------------------------------------------------
- Memory Architecture:
  * Physical Memory (RAM) vs. Virtual Memory (Address Spaces).
  * Memory Management Unit (MMU) & Translation Lookaside Buffer (TLB).
  * Page Tables (Multi-level paging, Huge Pages / Large Pages).
  * Page Faults (Minor/Soft vs. Major/Hard page faults).

- Allocation & Swapping:
  * Kernel Allocators: Slab / Slub / Slob allocators (Linux), Pool Allocator
    (Paged & Non-Paged Pool in Windows).
  * User Allocators: malloc/free, brk/sbrk, mmap, VirtualAlloc, HeapAlloc.
  * Swap / Paging: Swap partitions, swap files (Linux), pagefile.sys &
    swapfile.sys (Windows).
  * Out-Of-Memory (OOM) Handling: OOM Killer (Linux), Memory Compression.

4. STORAGE & FILE SYSTEMS
--------------------------------------------------------------------------------
- Storage Stack:
  * Block Devices & Partitions: MBR vs. GPT partition tables.
  * Volume Managers: LVM (Linux), Storage Spaces & Dynamic Disks (Windows).
  * RAID: Software & Hardware RAID (0, 1, 5, 6, 10).
  * Disk Encryption: LUKS / dm-crypt (Linux), BitLocker (Windows), FileVault.

- File System Types:
  * Linux: ext4, Btrfs, XFS, ZFS, F2FS, tmpfs, overlayfs.
  * Windows: NTFS, ReFS, FAT32, exFAT.
  * Network / Distributed: NFS, SMB/CIFS, Ceph, GlusterFS, SSHFS.
  * Optical / Read-only: ISO 9660, UDF, SquashFS.

- File System Internals:
  * Virtual File System (VFS) abstraction layer.
  * Metadata Structures: Inodes & Dentries (Linux), Master File Table / MFT
    (Windows).
  * Journaling & Copy-on-Write (CoW) for crash consistency.
  * Links: Hard Links, Symbolic Links (Symlinks), Junctions & Reparse Points.

5. DIRECTORY & SYSTEM HIERARCHIES
--------------------------------------------------------------------------------
- Linux Filesystem Hierarchy Standard (FHS):
  * /          : Root of the entire file system tree.
  * /bin, /sbin: Essential user and system binaries (symlinked to /usr).
  * /boot      : Kernel images (vmlinuz), initramfs, GRUB bootloader files.
  * /dev       : Device nodes (disks, terminals, null, random).
  * /etc       : System-wide plain-text configuration files.
  * /home      : Personal user directories.
  * /lib       : Shared libraries and kernel modules (/lib/modules).
  * /media, /mnt: Removable media and temporary mount points.
  * /opt       : Third-party / optional add-on software packages.
  * /proc      : Virtual filesystem exposing kernel & process runtime state.
  * /root      : Home directory for the superuser (root).
  * /run       : Volatile runtime data (PIDs, sockets) since last boot.
  * /sys       : Virtual filesystem (sysfs) for kernel objects & hardware.
  * /tmp       : Temporary files cleared on reboot.
  * /usr       : Secondary hierarchy for user utilities, libraries, docs.
  * /var       : Variable data (logs in /var/log, caches, spool, databases).

- Windows Directory Structure:
  * C:\Windows\System32 : Core OS executables, DLLs, drivers, CLI tools.
  * C:\Windows\SysWOW64 : 32-bit subsystem binaries on 64-bit Windows.
  * C:\Windows\WinSxS   : Windows Component Store (side-by-side assemblies).
  * C:\Program Files    : Installed 64-bit applications.
  * C:\ProgramData      : Shared application data across all users.
  * C:\Users\<User>     : User profile (Desktop, Documents, AppData).
  * Windows Registry    : Hierarchical configuration database (HKLM, HKCU, HKCR,
                          HKU, HKCC).

6. INPUT / OUTPUT (I/O) & DEVICE MANAGEMENT
--------------------------------------------------------------------------------
- Hardware Abstraction & Drivers:
  * Hardware Abstraction Layer (HAL) & Device Trees / ACPI.
  * Device Drivers: Kernel-mode drivers (.ko in Linux, .sys in Windows) and
    User-mode drivers (UMDF, FUSE, libusb).
  * Bus Subsystems: PCIe, USB, NVMe, SATA, SCSI, I2C, SPI, Thunderbolt.

- I/O Mechanisms:
  * Interrupts (IRQ), Interrupt Request Handlers, APIC, MSI/MSI-X.
  * Direct Memory Access (DMA) & IOMMU.
  * Polling vs. Interrupt-driven vs. Asynchronous I/O (io_uring, epoll, IOCP).
  * Character Devices (keyboards, serial) vs. Block Devices (SSDs, HDDs).

7. NETWORKING SUBSYSTEM
--------------------------------------------------------------------------------
- Network Stack (OSI / TCP-IP):
  * Link Layer: Ethernet, Wi-Fi (802.11), ARP, NDP, MAC addresses, VLANs.
  * Network Layer: IPv4, IPv6, ICMP, Routing Tables, NAT, IP Forwarding.
  * Transport Layer: TCP, UDP, QUIC, SCTP, Ports & Ephemeral Port Ranges.
  * Application Layer: DNS, DHCP, HTTP/HTTPS, SSH, SMB, NTP, SNMP.

- Virtual & Advanced Networking:
  * Loopback Interface (lo / 127.0.0.1 / ::1).
  * Network Bridges, Bonds/Teaming, TUN/TAP interfaces, veth pairs.
  * Network Namespaces & Containers.
  * Packet Filtering & Firewalls: netfilter (nftables, iptables), ufw (Linux);
    Windows Filtering Platform (WFP), Windows Defender Firewall (Windows).

8. SECURITY, IDENTITY & ACCESS CONTROL
--------------------------------------------------------------------------------
- Identity & Authentication:
  * Users & Groups: UID/GID (Linux), Security Identifiers / SIDs (Windows).
  * Password Storage: /etc/shadow (hashed passwords in Linux), SAM database &
    Active Directory / NTDS.dit (Windows).
  * Authentication Frameworks: PAM (Pluggable Authentication Modules), Kerberos,
    LDAP, OAuth/OIDC, Windows Hello, Biometrics.

- Authorization & Isolation:
  * Discretionary Access Control (DAC): POSIX permissions (rwx, SUID, SGID,
    Sticky Bit) and NTFS Access Control Lists (ACLs).
  * Mandatory Access Control (MAC): SELinux, AppArmor (Linux); Mandatory
    Integrity Control / MIC (Windows).
  * Privilege Escalation Controls: sudo, Capabilities (Linux); User Account
    Control / UAC (Windows).
  * Sandboxing & Virtualization: Namespaces, cgroups, seccomp (Linux); Job
    Objects, AppContainer, Hyper-V / VBS (Windows).

- Cryptography & Integrity:
  * Secure Boot & Measured Boot (TPM 2.0).
  * Code Signing & Driver Signature Enforcement.
  * Keyrings & Credential Stores: Linux Kernel Keyring, GNOME Keyring, Windows
    Credential Manager & DPAPI.

9. USER INTERFACE & GRAPHICS SUBSYSTEM
--------------------------------------------------------------------------------
- Command-Line Interfaces (CLI):
  * Shells: Bash, Zsh, Fish, sh (Unix/Linux); PowerShell, CMD (Windows).
  * Terminal Emulators & Multiplexers: TTYs, PTYs, tmux, screen, Windows
    Terminal, ConHost.

- Graphical User Interfaces (GUI):
  * Display Servers & Compositors: Wayland, X.Org / X11 (Linux); Desktop Window
    Manager / DWM (Windows).
  * Graphics APIs & Drivers: DRM/KMS, Mesa, OpenGL, Vulkan (Linux); DirectX,
    WDDM (Windows).
  * Desktop Environments: GNOME, KDE Plasma, XFCE, Cinnamon (Linux); Windows
    Shell / Explorer (Windows).

10. SYSTEM CONFIGURATION, LOGGING & PACKAGE MANAGEMENT
--------------------------------------------------------------------------------
- Configuration Management:
  * Environment Variables (PATH, HOME, USER, TEMP, etc.).
  * Scheduled Tasks: cron, systemd timers (Linux); Task Scheduler (Windows).
  * System Policies: sysctl kernel parameters (Linux); Group Policy / GPO &
    Local Security Policy (Windows).

- Logging & Telemetry:
  * Linux: systemd-journald (journalctl), rsyslog, dmesg, /var/log/*.
  * Windows: Windows Event Log (Application, Security, System), ETW (Event
    Tracing for Windows).

- Software & Package Management:
  * Linux: dpkg/apt (Debian/Ubuntu), rpm/dnf (RHEL/Fedora), pacman (Arch),
    Flatpak, Snap, AppImage.
  * Windows: winget, MSI (Windows Installer), MSIX, Chocolatey, Scoop.

11. ESSENTIAL SYSTEM COMMANDS REFERENCE
--------------------------------------------------------------------------------
[Process & Performance]
- Linux  : ps aux, top, htop, kill, pkill, nice, renice, uptime, vmstat, iostat
- Windows: tasklist, taskkill, Get-Process, Stop-Process, resmon, perfmon

[System & Hardware Info]
- Linux  : uname -a, lscpu, lsblk, lspci, lsusb, dmidecode, free -h, df -h
- Windows: systeminfo, msinfo32, dxdiag, Get-ComputerInfo, wmic, Get-Volume

[Services & Daemons]
- Linux  : systemctl status/start/stop/enable/disable <unit>, journalctl -u <unit>
- Windows: sc query/start/stop <svc>, Get-Service, Start-Service, services.msc

[File & Permission Management]
- Linux  : ls, cp, mv, rm, mkdir, find, grep, chmod, chown, tar, rsync
- Windows: dir, copy, robocopy, move, del, mkdir, findstr, icacls, takeown

[Networking & Diagnostics]
- Linux  : ip a, ip r, ss -tulnp, ping, traceroute, mtr, dig, curl, tcpdump
- Windows: ipconfig /all, route print, netstat -ano, ping, tracert, nslookup

[Users & Packages]
- Linux  : useradd, usermod, passwd, sudo, apt update && apt upgrade
- Windows: net user, net localgroup, winget install / upgrade / list
